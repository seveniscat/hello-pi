# 上台提示卡｜控制面主线 75 分钟版

**唯一主张：遇到工作流偏离预期，你能否看清、干预并改造 Agent 的工作方式？** Pi 是样本，不是唯一答案。四个场景都按“画面 → 痛点 → 操作与证据 → 判断标准”讲；不在结尾重放 Demo。

| 时间 | 唯一问题 | 画面 / 操作 | 必须保留的边界 |
|---|---|---|---|
| 00:00–04:00 | 同一条指令为什么突然变了？ | 构造一个修 CI 情境；四种失控；收一条经历 | 不冒充讲者亲历，不概括所有竞品 |
| 04:00–08:00 | 模型之外是谁组织工作？ | 循环图与任务统计结果 | 人工参考修复；不现场修小 bug |
| 08:00–11:00 | 本轮输入来自哪里？ | Context 来源清单、规则 diff | 可编辑规则不是权限；热更新 TUI 未彩排 |
| 11:00–15:00 | 哪些提醒值得写成程序？ | /verify 或真实 loader+exec 报告 | 不是 CI 门禁；报告不是界面直播 |
| 15:00–18:00 | 谁决定请求发给哪个模型？ | `npm run demo:router`，四行结果 | 目录 fixture，无真实模型与费用对照 |
| 18:00–20:00 | 能否定位并改变行为来源？ | 收一个“提醒还是确定动作”的例子 | 控制入口不能消除所有漂移 |
| 20:00–23:00 | 工具多，为什么 prompt 必须重？ | 区分接入、暴露和调用 | 历史只讲一分钟；不念功能列表 |
| 23:00–28:00 | 哪些结果进入后续推理？ | `npm run demo:codemode`；T-101；错误反例 T-103 | 真实 QuickJS；本地工具、手写脚本 |
| **27:00** | 停止 Codemode 排障 | 切到准备阶段 JSON | 不占后面场景 |
| 28:00–32:00 | 少返回是否等于没权限？ | “少说”与“少输入”；宿主计数仍为 1 | 无 MCP 传输；不编造节省比例；失败不回滚 |
| 32:00–34:00 | 支线为什么污染主线？ | 最小修复 vs archived:null | 不把未来需求混进当前验收 |
| 34:00–38:00 | 模型实际拿到了哪条路径？ | `npm run demo:sessions`，三份消息数组 | 手写消息/摘要，不是自动摘要质量测试 |
| 38:00–40:00 | 分支是不是整个环境回退？ | 文件仍保持修改；让听众选带回什么 | 会话树不是 Git / 文件快照 |
| 40:00–42:00 | 纠偏、追加、取消有什么区别？ | Steering / Follow-up / abort 三分法 | 当前 turn 与工具批次完成后才读取 Steering |
| 42:00–46:00 | 输入到底在哪一步生效？ | `npm run demo:steering`；A/B → steer → C/收尾 → follow-up | 真实 core loop，预置模型响应，无文件修改 |
| **45:00** | 停止队列演示排障 | 切到 trace 与请求输入记录 | 不改讲成“模型立即听话” |
| 46:00–48:00 | 一句“别发了”能撤回通知吗？ | 让听众回答，再给边界 | Steering 不是急停或补偿 |
| 48:00–50:00 | 分工究竟解决什么？ | 两个审查者、不同输入与返回契约 | 主版本不跑 Subagent；独立上下文非 OS 隔离 |
| 50:00–52:00 | 进程没了谁继续？ | A/B/C 与两种使用约束 | Durable 是独立实验性框架 |
| 52:00–56:00 | 恢复了哪一步？ | `npm run demo:durable`；A=1/B=2 | 自定义任务，无模型或外部通知 |
| **55:00** | 停止恢复演示排障 | 切到存储与三进程记录 | 保留通知故障窗口 |
| 56:00–59:00 | 完成记录缺失等于没发生吗？ | 通知已发但确认未保存 | 提交去重 / 工具重放 / 外部幂等分开讲 |
| 59:00–63:00 | 自由由谁维护？ | 权限、成本、回归；三种不等号 | 不把 Pi 包装为普遍更快、更便宜 |
| 63:00–65:00 | 带什么回家？ | 五问检查表 + 一个低风险实验 | 不先造平台，不要求换工具 |
| 65:00–75:00 | 哪个具体约束还没解决？ | 结论 → 条件 → 反例 → 验证 | 不猜版本、价格或未知包 |

## 五句判断标准

1. 本轮模型看到了什么，哪些行为由谁决定？
2. 工具从哪里来，本轮暴露什么、返回什么？
3. 历史怎样分支，哪些状态不会跟着回退？
4. 新指令在哪个边界进入循环？
5. 进程没了，谁续跑、谁核对不确定结果？

## 演示开头只说一句

“这里真实运行的是 **X**，预置的是 **Y**；这段验证 **Z**，不是模型质量测试。”把完整边界放在画面角标，不用每一段重复长免责声明。

## 失败兜底原话

- “本场这段没有在时间窗内完成。我用准备阶段实际运行的报告继续，不把它说成刚才成功。”
- “这段模型响应是测试预置，不是模型刚刚推理出来的。”
- “这个 TUI 或联网步骤还没彩排，今天不拿它作为实测证据。”

## 可删和不可删

- 可删：版本演进细节、冗长日志、路由额外讨论、Subagent 完整演示。
- 不可删：预置输入标记、会话不回滚文件、Steering 不立即截断、恢复不包办外部 exactly-once。
- 60 分钟版压缩例子；90 分钟版增加反例，具体时间跟随主讲稿附录，不把本卡 75 分钟硬截止直接套用。
- 上台前至少走两遍，其中一次主动切换兜底。不要在台上安装、升级或复制个人凭据。
